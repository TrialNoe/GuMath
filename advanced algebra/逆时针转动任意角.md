是否可以逆时针转动任意角
$$
R^{ 2 } \to R^{ 2 }:T(\bf{x})=\left[
\begin{matrix}
\cos\theta & -\sin \theta \\
\sin\theta & \cos \theta
\end{matrix}
\right]
\left[
\begin{matrix}
x_{1} \\
x_{2}
\end{matrix}
\right]
$$
```c
#include <math.h>  
#include <stdio.h>  
int main() {  
    double x, y, theta = .0;  
    scanf("%lf%lf%lf", &x, &y, &theta);  
    double T[2][2] = {  
        {cos(theta * M_PI / 180), -sin(theta * M_PI / 180)},  
        {sin(theta * M_PI / 180), cos(theta * M_PI / 180)}  
    };  
    printf("(%lf,%lf)", T[0][0] * x + T[0][1] * y, T[1][0] * x + T[1][1] * y);  
}
```
